# The Robot Vacuum's Funniest Excuse

One line, at most 120 characters, in which a robot vacuum explains why it
missed a spot — entered in the make.fun competition
[The Robot Vacuum's Funniest Excuse](https://make.fun/competitions/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).

## The entry

> The dust bunny unionised, and I respect a picket line.

## How it works

`main.py` writes that single line to `entry.txt` in the output directory
named by `MAKEFUN_OUTPUT_DIR` (default `/output`). It reads no input files
and writes nothing else.
